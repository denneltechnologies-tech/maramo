# Features

What Classivo ERP can do, grouped the way a school runs. Each line links to the package page. Packages marked "in progress" are not finished yet.

## Admissions and front office
- Student admission, guardians, categories and documents: [students](/packages/students)

## Students
- Student records, guardians, documents, promotion: [students](/packages/students)
- Daily and subject-wise attendance: [students](/packages/students)

## Academics
- School, branch, academic session, classes, sections, subjects: [core](/packages/core)
- Class timetable with clash detection and a timetable generator: [timetable](/packages/timetable)

## Exams and results
- Exam groups, schedules, marks entry, results, ranking, publishing: [exams](/packages/exams)
- Grading schemes (CBSE, ICSE/ISC, state boards): [grading](/packages/grading)
- Report cards, marksheets, certificates, ID cards, transfer certificates as PDF: [report-cards](/packages/report-cards)

## Fees
- Fee heads, groups, allocation, concessions, late fines, receipts, refunds, defaulters and reminders: [fees](/packages/fees)

## Staff
- Staff, departments, attendance, leave, salary structures, payroll with an India preset: [hr](/packages/hr)

## Not in this repository
Mobile apps, push notifications and the multi-school hosted layer. See the [overview](/).
